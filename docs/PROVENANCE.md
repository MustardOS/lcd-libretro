  - Licence: BSD-3-Clause (hap).

## Changes from MAME

- The `sm510_base_device` class hierarchy became one C structure with a variant field.
- The virtual overrides became variant checks.
- Instruction behaviour and cycle counts are unchanged.
- The PC LFSR, memory maps and mirrors are unchanged.
- The divider, timers, melody controller and LCD drivers are unchanged.
- The MAME framework parts were removed: `address_space`, `devcb`, `emu_timer`, `save_item` and the debugger hooks.
- Memory maps became address functions.
- Callbacks became function pointers.
- A 32.768 kHz oscillator loop drives the timers.
- Each oscillator tick runs the CPU for its share of the clock, then the divider.
- Every 32 ticks the LCD strobe and decay run at 1024 Hz.
- With this order the CPU state matches MAME on every tick.
- `make reference-check` confirms the match.
- SM590, the disassembler and MAME's SVG screen device were not adapted.
- The SVG renderer is original.
- The SVG renderer uses MAME's `x.y.z` segment names.

- `roms/` and `tests/fixtures/` hold original works.
